# 智慧工务管理系统 · 产品原型

基于 HTML、CSS、JavaScript 的可交互工程协作原型。

## 在线演示

在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存后获得在线地址。

- 登录页：`index.html`
- 直接体验：`系统工作区.html`
- 演示账号：`19923456789`，密码：`Test123.`
- 进入后可在右上角切换建设、设计、监理、施工和管理员角色。

## 演示范围

项目看板、工程答疑、会议协调、图纸变更、资料管理与管理员流程管理。工程答疑和会议预置了虚构测试数据。设置中的演示数据后台可恢复默认状态。

流程记录保存在访问者自己的浏览器中，附件使用浏览器本地存储。不同设备的数据不会互相同步。角色切换用于演示业务规则，不是真实身份认证。

AI 问答需要服务端，静态版不连接 AI、不收集或保存模型密钥。

## 更新

此仓库只包含可公开的前端代码与虚构演示数据。主工程执行 `node scripts/build-static.mjs` 后，将生成目录同步到本仓库并提交即可更新。
